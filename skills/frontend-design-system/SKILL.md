# 前端设计系统（Paper UI）

## Overview

一键生成符合用户固定审美与交互习惯的前端界面。核心主张：**暖米白纸感底色、方圆结合圆角（方角面板 + 单角切直的气泡）、克制的墨黑+赤陶双色、所有开关即时生效、删除回退必弹窗确认、无头 Edge 截图实测验收**。

## 工作流（按序执行）

### 1. 确认设计语言（动手前）
向用户确认三件事：色板基调（默认暖米白纸感）、明暗（默认浅色）、圆角风格（默认方圆结合）。无异议则直接用默认值，不要追问。

### 2. 先建设计系统，再写组件（禁止跳过）
- 若用 React+Vite+Tailwind：先 `tailwind.config.ts` + `src/index.css` 定义全部令牌（HSL CSS 变量），组件中**禁止出现裸色类**（text-white/bg-blue-500 一律用令牌）。
- 色板、圆角、字体、阴影令牌值 → `references/design-tokens.md`，直接照抄。
- 主题预设（森林/薄荷/蜜蜂/羊皮纸）与亮暗切换 → 同一文件，真实覆写 CSS 变量。

### 3. 布局
- 三栏工作台（项目栏/主区/终端）尺寸与侧栏滑推动画 → `references/design-tokens.md` 布局段。
- 聊天主区列宽默认 880px（紧凑 640/宽松 1040 可切换）。
- 窄窗（<1100px）自动收起右侧终端；原生滚动条一律 `.no-scrollbar` 隐藏。

### 4. 聊天交互（用户已固化的形态，必须全做）
→ `references/chat-patterns.md`：流式无气泡 Agent 输出、0.1s 精度计时、圆头像+三操作键（复制/删除/回退）、删除回退弹窗确认、工具审批卡（批准/拒绝/在终端运行）、任务过程面板（思考+调用+spinner）、输入框（红框、虚线下移、执行域/权限/模型下拉、回形针附件独立等宽区、向上箭头发送键、任务进行中可再发定制干预）。

### 5. 设置页
→ `references/settings-patterns.md`：全屏覆盖层+退出动画、hash 导航、**内容必须换成当前项目的真实情况（严禁照搬其他产品的设置项）**、所有开关必须真实接线（禁占位）、Toggle 用主题 accent 色不用绿色。

### 6. 验收（不通过不收工）
→ `references/verification.md`：`npm run build` + `scripts/shot.mjs` 无头 Edge 截图 + DOM 断言交互。用户偏好少开真窗，一律用无头方案。

## 关键红线（违反即返工）

1. 面板/按钮 2px 方角，气泡 14px 圆角但**必须有一个角切直**，chip 胶囊形——拒绝千篇一律大圆角。
2. Agent 消息**无头像、无气泡**；用户消息**必须有圆头像**（贴气泡右侧）。
3. 一切删除/回退操作弹窗确认；输入框边框用主题红（destructive/accent）。
4. 设置项禁止占位；禁止抄袭其他产品的设置内容，按当前项目真实功能重组。
5. 每批改动必须实际验证：构建 + 无头截图 + 交互断言，三者全绿才算完成。
