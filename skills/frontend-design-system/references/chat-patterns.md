# 聊天交互规格（Chat Patterns）

## 消息形态（两条铁律）

1. **Agent：无头像、无气泡**——纯文本平铺 + 逐段流式；用户消息：墨黑气泡右对齐 + **圆形头像贴气泡右侧**。
2. 用户消息操作键（悬停常显）：**复制 / 删除 / 回退**，删除与回退**必须弹窗确认**。

## Agent 流式输出（StreamedText）

- 每条新回复逐段吐出：9 字符 / 16ms，末尾 2px accent 色闪烁光标（animate-blink）。
- **流式只放送"新到"消息**：维护 `streamedRef: Set<messageId>`，初始载入历史消息 id；切换任务/回看历史 = 直接完整显示，绝不重播打字机。
- 设置项"AI 回复流式动画"关闭时全部直显。

## 0.1s 精度计时器

- 每条 Agent 回复**开头**显示 `⏱ 已用时 X.Xs …`（mono 10.5px 灰色）。
- 进行中每 100ms 刷新；过程消息到达（finishedAt 落盘）自动停表去掉"…"。
- 用户消息可带"定制干预"角标（任务进行中再次发送 = 中途干预，发送键此时变 accent 色、tooltip 提示"定制当前任务"）。

## 工具调用卡（单行紧凑，参考 Qoder 工具行样式）

```
[Wrench 图标] tool_name  |  mono 命令（截断） | [执行域 chip] | [✓批准][✗拒绝][在终端运行]
```
- pending：三个按钮；已决：状态文字（已批准=success/已拒绝=destructive）。
- **在终端运行**：把命令直接送右侧 WSL 终端执行（自动确定，不走审批），终端自动展开。
- 有 output 时右侧出现展开箭头，展开显示执行输出。
- 命令必须过门禁（--npu-arch / soc 分箱后缀 / Dump 开关），违规命令直接拒绝并给修正建议。

## 任务过程面板（TraceBlock）

- 折叠头：`任务过程 N 步` + 当前进行中步骤名；进行中步骤 = 旋转 LoaderCircle（accent），完成 = 苔绿对勾，等待 = 灰点。
- 每步可展开：`思考：`小字灰 + 调用列表——工具（Wrench+工具名+mono 命令+执行域 chip）/ 技能（Sparkles+技能名）。
- 新消息到达时过程面板作为 trace 消息追加进消息流，跟随对话历史。

## 输入框（Composer，参考用户给定图样）

```
┌─ rounded-xl，destructive 红边框 ─────────────────────┐
│  textarea（2 行，min-h 38px，底部大留白）              │
│  ┄┄┄┄ 虚线分隔（贴底部按钮行）┄┄┄┄                    │
│  [+] [📎] [执行域▾] [权限▾]    [⚡模型▾] [↑发送]      │
└──────────────────────────────────────────────────────┘
```
- 附件 chip 放在输入框**上方独立等宽行**（不撑高输入框），可单个删除。
- 加号 = 快捷操作菜单（新建任务/新建项目）；回形针 = 上传文件。
- 执行域下拉：本地/沙箱/远端 NPU；权限下拉 = Qoder SDK 的 7 个 PermissionMode（plan/default/acceptEdits/dontAsk/auto/bypassPermissions/yolo，高危两项标红）。
- 模型下拉读取设置里配置的模型（显示名称 + effort 徽标）。
- 发送键 = 向上箭头；输入框与消息列共用同一 max-width 保证两侧对齐。
- **无"Enter 发送"提示栏**；底部区域与聊天页同底色、无分界线。

## 悬浮定位导航条（DeepSeek 式）

- 聊天区右侧竖排小横条（每消息一段），悬停聊天区才显示（opacity 过渡，不可见时 pointer-events-none）。
- 滚轮上下选择、点击跳转对应消息；当前可视段 accent 高亮加宽。
- 滚动监听：取容器 35% 高度处最近的消息段。

## 阶段 stepper

任务头显示六阶段（环境/原型/Tiling/编译/调试/调优）：已过=success 淡底、当前=accent 实底、未到=灰。
